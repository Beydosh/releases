# Beydosh PIM Beta-Updatekanal

Aktueller veröffentlichter Stand: **0.9.121** für Windows x64.

- [Änderungen und Updatepaket](https://github.com/Beydosh/releases/releases/tag/v0.9.121)
- [Signierter Kanalindex](latest.beydosh.json)
- [Signiertes Manifest](0.9.121/manifest.beydosh.json)

0.9.121 ergänzt den Website-Abgleich des Standard-Versandstandorts. Nur der bestätigte Unternehmensinhaber kann die gemeinsame Adresse ändern. Bestehende lokale Adressen werden erst nach ausdrücklicher Übernahme und Speicherung geteilt. Kanal-Ausnahmen bleiben lokal; eBay-Standorte und Angebote werden nicht automatisch geändert. Die Version enthält auch die bisherigen Aktualisierungen.

Die Aktualisierung erfolgt über Beydosh PIM. Der passende Launcher wird mit dem normalen PIM-Update übernommen. Die Paketdateien sind keine ausführbaren Installer.

Ab 0.9.108 ist ein kontofähiger Launcher ab Version 0.9.108 erforderlich. Die Anmeldung ist verpflichtend. Es wird eine geschützte Sitzung gespeichert, kein Passwort. Lokale Geschäftsdaten werden durch die Kontoanmeldung nicht automatisch synchronisiert.

Für den Start ist neben der Anmeldung die Freischaltung des Kontos erforderlich. Unternehmensname, Logo und Standard-Versandstandort können mit dem Website-Konto abgeglichen werden. Produkte, Preise, Bestände, Shopwährung und Mail-Zugangsdaten werden dadurch nicht automatisch zentral synchronisiert.

Dies ist eine Beta-Vorversion. Release-Prüfungen und ihre Grenzen stehen bei der jeweiligen Version. Eine Sicherheitsprüfung ist keine Garantie auf Schadsoftwarefreiheit; eine erfolgreiche Installation belegt keine vollständige Live-Verkaufsabnahme.

Prüfstand 2. November 2026: Für alle 119 veröffentlichten Release-Tags liegt ein Manifest im Kanal vor. Index und Manifest von 0.9.121 haben gültige Signaturen; der öffentliche Paketdownload stimmt mit der signierten Dateigröße und SHA-256-Prüfsumme überein. Historische Versionsnummern werden nur übernommen, wenn dazu tatsächlich ein Release veröffentlicht wurde.

Neue Setups werden derzeit nicht veröffentlicht. Historische signierte Dateien bleiben unverändert; maßgeblich für Aktualisierungen ist der vom Launcher geprüfte Kanalindex.
